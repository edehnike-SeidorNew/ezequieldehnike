## Resumen

Pokédex interactiva construida sobre la **PokeAPI**. Permite buscar Pokémon, explorar las relaciones entre tipos y recorrer los Pokémon por generación.

## Funcionalidades

- **Pokédex** con buscador y tarjetas por Pokémon, con sus tipos y datos principales.
- **Explorador de tipos**: al elegir un tipo se ve contra qué es fuerte, débil o inmune, tanto atacando como defendiendo.
- **Generaciones**: listado de Pokémon organizado por generación.
- **Estado global** con Zustand para compartir datos entre pantallas.
- Diseño responsivo con fondos degradados.

## Tecnologías

- **Next.js 14** (App Router) y **TypeScript**.
- **Tailwind CSS** y componentes base de **shadcn/ui**.
- **Zustand** para el estado.
- **PokeAPI** como fuente de datos.

## Aprendizajes

Consumir una API pública con muchos recursos relacionados me enseñó a organizar las llamadas, compartir el estado entre pantallas con Zustand y mantener la interfaz clara mientras se cargan los datos.
