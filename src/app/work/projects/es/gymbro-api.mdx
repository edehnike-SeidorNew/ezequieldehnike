## Resumen

GymBro es una API REST para la gestión de un gimnasio, desarrollada como proyecto final de la materia THP2 en ORT. Cubre el alta de usuarios, socios, membresías, pagos y clases, con inscripción y baja de socios en cada clase.

## Funcionalidades

- **Registro y login** de usuarios con contraseñas hasheadas con **bcrypt** y sesiones con **JWT**.
- **CRUD completo** de socios, membresías, pagos y clases.
- **Inscripción y desinscripción** de socios a clases.
- **Fotos de perfil** para usuarios y socios, subidas con un middleware de carga a **Supabase Storage**.
- **Rutas protegidas** con un middleware que verifica el token.

## Tecnologías

- **Node.js** y **Express 5**.
- **MongoDB** con **Mongoose**.
- **JWT** y **bcryptjs**.
- **dotenv** para la configuración por entorno.
- Arquitectura por capas: rutas, controladores, modelos y middleware.

## Aprendizajes

Separar rutas, controladores y modelos hizo que la API fuera fácil de extender. Aprendí a proteger rutas con middleware y a manejar la subida de archivos hacia un servicio externo.
