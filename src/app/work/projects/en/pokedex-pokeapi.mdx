## Overview

Interactive Pokédex built on top of the **PokeAPI**. It lets you search Pokémon, explore the relationships between types and browse Pokémon by generation.

## Features

- **Pokédex** with search and a card per Pokémon, showing types and main data.
- **Type explorer**: selecting a type shows what it is strong against, weak against or immune to, both attacking and defending.
- **Generations**: list of Pokémon organized by generation.
- **Global state** with Zustand to share data between screens.
- Responsive design with gradient backgrounds.

## Technologies

- **Next.js 14** (App Router) and **TypeScript**.
- **Tailwind CSS** and **shadcn/ui** base components.
- **Zustand** for state.
- **PokeAPI** as the data source.

## Learnings

Consuming a public API with many related resources taught me to organize API calls, share state between screens with Zustand and keep the interface clear while data loads.
