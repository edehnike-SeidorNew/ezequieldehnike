## Overview

**Freelance project** built for a client. Landing page for a custom ironwork and barbecue grill workshop in Castelar, Buenos Aires. It showcases their work and products and makes direct contact over WhatsApp easy to request a quote. It is a static page, light and easy to maintain.

## Features

- **Catalog by category**: tapping a product opens a modal with a large photo and its details. On mobile each category turns into a horizontal slider.
- **Carousel of featured jobs** with a *coverflow* effect (Glide.js) on large screens and native *scroll-snap* on mobile.
- **WhatsApp**: contact button, floating button and prefilled messages per product.
- **Embedded Google Maps** with the workshop location.
- **Scroll animations**, responsive menu and optimized images.

## Technologies

- Plain **HTML, CSS and JavaScript**, no frameworks or build step.
- **Glide.js** for the carousel.

## Learnings

Working without a framework forces you to keep the CSS and JavaScript structure tidy. Optimizing images and using *scroll-snap* on mobile improved the touch experience and loading speed.
