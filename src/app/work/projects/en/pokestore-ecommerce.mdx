## Overview

Online shop for Pokémon cards built with HTML, CSS and JavaScript, with no frameworks or external libraries. It is the final project of a JavaScript course.

## Features

- **Products** fetched with `fetch` from a JSON file and rendered dynamically as cards.
- **Cart** saved in `localStorage`, so it is not lost when closing or reloading the page.
- **Cart counter** updated in real time, quantity editing, product removal, per-product subtotal and order total.
- **Simulated checkout** that empties the cart.
- **Contact form** with JavaScript validation (required fields and email format) that sends the data with Formspree.
- **Customer reviews** and responsive design with Flexbox and Grid.

## Technologies

- **HTML, CSS and JavaScript**, split into files by responsibility.
- **Fetch API** and **localStorage**.
- **Formspree** for the form.

## Learnings

Splitting the code into modules (cart, storage, interface) showed how to organize a larger project without a framework. I also practiced DOM manipulation and state handling in the browser.
